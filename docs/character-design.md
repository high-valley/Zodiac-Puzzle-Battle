# キャラの外見を決めるための資料

12星座のキャラの外見（性別・年ごろ・髪や衣装・持ち物・モチーフ）を、星座の神話と古い星座の書物をもとに、ユーザーと質問しながら決めていくための資料。決まったものから仕様書 18.4 に移す。

## 決まっていること（2026-11-03）

- 見た目は **みな若め**。
- **男女は半々**（6人ずつ）：男性＝おひつじ・ふたご・しし・さそり・やぎ・みずがめ、女性＝おうし・かに・おとめ・てんびん・いて・うお。
- **星座の精（独自のキャラ）**にする。神話の人物そのものではなく、星座の力を宿した独自のキャラで、神話は持ち物・衣装の意匠・性格づけのモチーフとして使う。
- **ふたご座は双子の2人組**で1キャラ（ゲームでは1人分の枠）。男性の双子。
- **動物の要素は少しだけ体に付ける**：角などを一点だけ体に付け（参考画像のおひつじ座の角くらい）、ほかは装身具や衣装の意匠で表す。
- 性能（役割・得意な色・必殺の形）は決まっている（仕様書 12.3）。外見はそれと食い違わないようにする（必殺の色の衣装や、形にちなんだ持ち物など）。
- 画像生成で画面の雰囲気を出すときは、キャラは描かない（`docs/art-prompts.md`）。キャラの絵は外見が決まってから作る。

## 調べた書物

ギリシャ・ローマの星座神話は、主に次の古い書物に残っている。どれも星座ごとに「何が星になったか」と、別の言い伝えを並べている。

- **アラトス『パイノメナ（星の現象）』**（紀元前3世紀）：星座を詩で歌ったもの。
- **偽エラトステネス『カタステリスモイ（星座になったものたち）』**（紀元前3世紀の伝え）：星座ごとの由来の神話。
- **ヒュギヌス『天文詩（De Astronomica）』第2巻**（1世紀ごろ）：上の2つや、もっと古い作者の説をまとめたもの。下の表の「2.20」などはこの本の節。
- 占星術の性格（火・地・風・水の4つの元素、活動・不動・柔軟の3つの性質、支配する星）は、プトレマイオス『テトラビブロス』（2世紀）以来の伝統による。神話とは別の流れだが、キャラの性格づけの手がかりになる。

5. **「若め」の幅**：10代後半〜20代前半くらいでそろえるか、少年少女っぽいキャラも入れるか。
