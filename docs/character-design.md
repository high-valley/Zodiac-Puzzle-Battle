# キャラの外見を決めるための資料

12星座のキャラの外見（性別・年ごろ・髪や衣装・持ち物・モチーフ）を、星座の神話と古い星座の書物をもとに、ユーザーと質問しながら決めていくための資料。決まったものから仕様書 18.4 に移す。

## 決まっていること（2026-11-03）

- 見た目は **みな若め：10代後半〜20代前半**でそろえる。
- 衣装は **古代ギリシャ風**でそろえる（下の「衣装の決まり」）。
- **将来は着せ替え（スキン）**ができるようにする（下の「スキンを見込んだ決まり」）。
- **男女は半々**（6人ずつ）：男性＝おひつじ・ふたご・しし・さそり・やぎ・みずがめ、女性＝おうし・かに・おとめ・てんびん・いて・うお。
- **星座の精（独自のキャラ）**にする。神話の人物そのものではなく、星座の力を宿した独自のキャラで、神話は持ち物・衣装の意匠・性格づけのモチーフとして使う。
- **ふたご座は双子の2人組**で1キャラ（ゲームでは1人分の枠）。男性の双子。
- **動物の要素は少しだけ体に付ける**：角などを一点だけ体に付け（参考画像のおひつじ座の角くらい）、ほかは装身具や衣装の意匠で表す。
- 性能（役割・得意な色・必殺の形）は決まっている（仕様書 12.3）。外見はそれと食い違わないようにする（必殺の色の衣装や、形にちなんだ持ち物など）。
- 画像生成で画面の雰囲気を出すときは、キャラは描かない（`docs/art-prompts.md`）。キャラの絵は外見が決まってから作る。

## 調べた書物

ギリシャ・ローマの星座神話は、主に次の古い書物に残っている。どれも星座ごとに「何が星になったか」と、別の言い伝えを並べている。

- **アラトス『パイノメナ（星の現象）』**（紀元前3世紀）：星座を詩で歌ったもの。
- **偽エラトステネス『カタステリスモイ（星座になったものたち）』**（紀元前3世紀の伝え）：星座ごとの由来の神話。
- **ヒュギヌス『天文詩（De Astronomica）』第2巻**（1世紀ごろ）：上の2つや、もっと古い作者の説をまとめたもの。下の表の「2.20」などはこの本の節。
- 占星術の性格（火・地・風・水の4つの元素、活動・不動・柔軟の3つの性質、支配する星）は、プトレマイオス『テトラビブロス』（2世紀）以来の伝統による。神話とは別の流れだが、キャラの性格づけの手がかりになる。

**性別（男女6人ずつ。2026-11-03 決定）**

- 男性：おひつじ・ふたご・しし・さそり・やぎ・みずがめ
- 女性：おうし・かに・おとめ・てんびん・いて・うお
- 決め方（キャラは神話の人物そのものではなく星座の精だが、性別は手がかりにならう）：
  - 人物の星座は、神話の人物の性別：ふたご（兄弟）・おとめ（アストライア）・みずがめ（ガニュメデス）・うお（アフロディテ）・やぎ（アイギパン／パーン）。てんびんは天秤の持ち主とされたアストライアにならう。
  - 動物の星座は、星にした神や関わる人物、参考画像、役割で決めた：おひつじ（参考画像の青年）・しし（獣の王）・さそり（参考画像の青年）は男性、かに（ヘラが星にした・月）は女性。
  - 神話とずれるのは いて座（神話のクロトスもケイローンも男性。参考画像どおり女性）と、おうし座（ゼウスの化身は男性だが、乗せたエウロペや、イオ・ヒュアデス・プレアデスの女性の話が多い）。
- 役割でみると、攻撃10人は男性6・女性4、回復2人（かに・おとめ）はどちらも女性になる。

## 衣装の決まり（古代ギリシャ風）

- 基本の形：キトン（肩で留めて腰帯を締める長い衣）、ペプロス（女性の、肩で留める重ねの衣）、ヒマティオンやクラミュス（肩にかける外套）、編み上げのサンダル。
- 装身具：肩の留め金（フィブラ）、腕輪、額飾りや月桂冠など植物の冠。金具は細い金。
- 戦う役の装備も古代ギリシャ風：胸当て（革や青銅）、すね当て、丸い盾、短い剣や槍、弓。全身を覆う中世の鎧にはしない。
- 色：生成りや白の布を基本に、必殺の色（仕様書 12.3：赤・青・緑・ピンク）を差し色にする。衣のふちに雷文（メアンダー）や波の文様の帯。
- 露出は控えめ（仕様書 16章-17・19.5）。

## スキンを見込んだ決まり（将来の着せ替え）

- 1人に基本の姿（古代ギリシャ風）と、あとから足すスキン（別の衣装）がある。中身や手に入れ方（ガチャ・イベント・購入など）は未決定（仕様書 19章）。
- どの衣装でも同じキャラと分かるように、**衣装で変えないもの**を1人ずつ決めておく：髪の色と髪型の大きな形、目の色、体に付けた動物の要素（角など一点）、星座の記号、必殺の色の差し色。
- 絵は、衣装ごとに立ち絵・バストアップ・アイコンの3種類をそろえる（仕様書 18.3）。顔の向きや立ち位置をそろえておくと、画面の配置を変えずに差し替えられる。
- 性能はスキンで変えない（見た目だけ）。
