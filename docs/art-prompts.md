# 雰囲気を決めるための画像生成プロンプト

仕様書 11章（画面構成）・18章（アート素材）をもとに、画面全体の雰囲気の案を何パターンか出すためのプロンプト。仕様書 18.1 の手順1にあたる。

- **目指す見た目が決まった（2026-11-03）**：`docs/ui-reference/10-target-home.jpg`（ホーム）と `11-target-orbs.jpg`（オーブ）。ほかの画面を出すときは、この2枚を添付して下の **雰囲気J** を使う。
- **キャラと敵は描かない**（2026-11-03 決定）。キャラの見た目は `docs/character-design.md` で別に決めるので、ここでは画面の枠・背景・部品・色・質感だけを比べる。キャラと敵が入る場所は「空けておく場所」として指定する。
- 気に入った案が決まったら、部品ごとの書き出し用プロンプト（18.3）を別に作る。

## 使い方

1. 次の4つをこの順に貼る：**共通の前提** → **画像生成らしさを抑える指定** → **雰囲気の方向（A〜I）から1つ** → **画面から1つ**。
2. 縦長で出力する（生成ツールで選べる縦長の最大サイズ。たとえば 1024×1536）。
3. まず「ホーム」をいくつかの方向で出して方向を絞る → 選んだ方向で「バトル」→ 残りの画面。
4. 2枚目からは、気に入った1枚目を添付して「添付の画像と同じ色・質感・部品の形で、次の画面を」と書き足す。
5. 出てきた画像の気になる所は、下の **直すときの追い指示** をそのまま送る。

## 共通の前提（毎回貼る）

```text
スマートフォン縦画面のファンタジーRPG「アストラクロニクル（ASTRA CHRONICLE）」の、ゲーム画面のUIデザイン案を1枚作ってください。

【ゲームの内容】
12星座をモチーフにした仲間たちと、パズルで魔獣と戦うゲーム。パズルは5×5のマス目に丸い宝珠（オーブ）が並び、2×2の4個を回して、同じ色を縦か横に3個以上そろえて消す。

【この画像で見たいもの】
- 画面の枠・背景・ボタン・パネル・アイコン・色・質感の方向性。
- 人物・動物・魔獣は描かない。キャラクターや敵が入る場所は、何も置かずに背景だけを見せる（あとで別に描いて重ねる）。

【必ず守ること】
- 実際に配信されているゲームの画面を、正面からそのまま撮った1枚のスクリーンショットとして描く。スマートフォン本体の枠、手、机、斜めの見え方、ポスターのような演出は入れない。
- 上下の端（時計やホームバーの位置）には大事なものを置かない。
- ボタン・見出し・数値・説明の文字は入れない。文字が入る場所は無地の帯や枠にする。タイトルロゴだけは文字を入れてよい。
- 画面でいちばん鮮やかなのはオーブの4色。背景・枠は彩度と明るさを抑える。
- オーブは4色とも同じ丸い宝珠で、中に白い単純な記号：赤（#E5484D）＝三角、青（#3D8BF2）＝ひし形、緑（#36B37E）＝四角、ピンク（#EF7FBF）＝ハート。
- 部品は縦横の線にそろえて整列させ、左右の余白をそろえる（画面の幅の約4%）。
```

## 画像生成らしさを抑える指定（毎回貼る）

画像生成AIの絵によく出るくせ（全体の黄ばみ、どこもかしこも光る、キラキラの粒だらけ、つるつるの光沢、装飾の詰め込み、ポスターのような構図）を、ひとつずつ打ち消す指定。

```text
【仕上げの指定（画像生成らしさを避ける）】
- 色：指定した色コードとその明暗だけを使う。画面全体に黄色や茶色のフィルターをかけない（白は白、紺は紺のまま）。グラデーションは2色まで、なだらかに。
- 光：光源は左上の1つだけ。光る（グロー）のはオーブ、選ばれている部品、画面の指定で「光る」と書いた所だけ。それ以外の枠・ボタン・文字のまわりに光のにじみを付けない。レンズフレア、光の筋、ぼけ（ボケ玉）、もや、煙は入れない。
- 星：背景の星は小さな点を控えめに。キラキラした十字の光や光の粒は、画面全体で10個以下（まだ多ければ、追い指示でさらに減らす）。
- 質感：つや消し。プラスチックや飴のようなつるつるの光沢、3DCGの質感にしない。**ただしオーブだけは例外**：つやのある宝珠で、中にその色の星雲と小さな星が見え、外側にやわらかい光（添付の目標画像どおり）。金は「細い線の金具」として描き、塊の金にしない。ほんのわずかな紙や布の粒子感があってよい。
- 線：枠の線の太さは2種類（太い線と細い線）にそろえる。輪郭はくっきり、ぼかさない。
- 装飾：飾りは「星」「星座の線（点と細い線）」「円弧」の3つのモチーフだけ。唐草・羽・宝石の盛り合わせ・リボンは使わない。飾るのは見出しの左右・パネルの四隅・主なボタンだけで、ほかは無地。
- 構図：左右対称の豪華な構図にしない。UIの並びに従った、使える画面として描く。背景の奥行きは2〜3層まで。
- 背景：城・神殿・塔・遺跡・家・柱・柱廊・アーチ・宙に浮いた島などの建物は描かない（よくある画像生成の背景になるため）。背景は空・模様・素材の質感で作る。
- 文字：意味のない文字や記号の並びを描かない。文字が入る場所は無地のまま。
- 雰囲気：「壮大な」「幻想的な」ポスターではなく、毎日開いても疲れない、落ち着いた遊びやすいゲーム画面。
- このあとの「雰囲気」の指定（色・飾りの形・光・質感・奥行き）が上と違うときは、雰囲気の指定を優先する。画面の指定にある「金色」のボタンは、雰囲気で決めた主なボタンの色に読み替える。
```

## 雰囲気の方向（1つ選ぶ）

どの方向も、背景に建物（城・神殿・塔・遺跡・家・柱・柱廊・アーチ・浮いた島）は描かない。背景は空・模様・素材の質感で作る（2026-11-03 決定。ネットでよく見る画像生成の背景に似てしまうため）。

| 方向 | ひとことで |
|---|---|
| **J 紺の夜空と雲（採用）** | 目標画像（10-target-home）の見た目。これを使う |
| A 紺と金の星空 | 王道。静かな夜空に細い金の線 |
| B 夜明けのパステル | やわらかく親しみやすい |
| C アンティークの星図と天球儀 | 知的で大人っぽい |
| D 宝石とステンドグラス | 神秘的で華やか（今いちばん好評） |
| D2 夜明けのステンドグラス | D を明るく、青と金で軽やかに |
| D3 星図のステンドグラス | D の模様を、星座と星図で組み立てる |
| E 古代ギリシャのモザイク | 小石とタイルの手ざわり。衣装の古代ギリシャ風と合う |
| F 古代ギリシャの壺絵 | 黒地に赤茶の線画と雷文。きりっとした2色 |
| G 切り絵の夜空 | 紙を重ねた影絵。やさしく手づくりの温かみ |
| H 星を映す夜の海 | 水平線と、水面に映る星座。広く静か |
| I 金糸の刺繍 | 濃紺の布に金糸で縫った星座。上品でやわらかい質感 |

### J：紺の夜空と雲（採用。目標画像の見た目）

目標画像 `10-target-home.jpg`・`11-target-orbs.jpg` を添付し、この指定と一緒に貼る。

```text
【雰囲気J：紺の夜空と雲（添付の目標画像の見た目）】
- 添付の1枚目（ホーム）と同じ色・質感・部品の形で描く。添付の2枚目のオーブをそのまま使う。
- 色：夜空 #0D1638 → #1E2A54、雲とパネルの地 #273569 → #43518A、金 #D49B59 → #F1C073（いちばん明るい所 #FCE5A7）。
- 背景：紺の夜空に、紙を重ねたようなやわらかい雲の層。小さな点の星と、細い金の線の星座。建物は描かない。
- 部品：紺のパネルに細い金の二重線の枠。枠の角や中央に小さな四芒星の飾り。ゆるやかな金の曲線を、見出しやボタンのまわりに少しだけ。小さなアイコンボタンは菱形。主なボタンは金地で、両端に金の飾り。
- ひとことで：添付の目標画像と並べて同じゲームに見えること。
```

### A：紺と金の星空（王道）

```text
【雰囲気A：紺と金の星空】
- 色：夜空の紺 #0B0F2E → #151B45、金 #E9C46A（細い線だけ）、白 #E8E4D8（少し）、差し色の紫 #5B3FA0（ごく少し）。
- 背景：建物のない静かな夜空。細い天の川と、小さな点の星。地平線も描かない。
- 部品：紺の半透明のパネルに細い金の枠。主なボタンだけ金地。
- ひとことで：荘厳だが落ち着いた、王道の星空ファンタジー。
```

### B：夜明けのパステル（やわらかい・親しみやすい）

```text
【雰囲気B：夜明けのパステル】
- 色：薄紫 #E9E1F3、桃 #F6D9E4、水色 #D4E8F6、シャンパンゴールド #D8C29A（細い線だけ）、文字が入る帯は紺 #2A2F5A。
- 背景：夜明け前の淡い空のグラデーションと、薄い雲の層だけ。建物は描かない。白っぽくなりすぎないよう、下のほうは少し濃いめの紫で締める。
- 部品：角の丸い白いパネルに細いシャンパンゴールドの枠。影はごく薄く。
- ひとことで：絵本のようにやわらかく、親しみやすい。ただしオーブの4色はくっきり。
```

### C：アンティークの星図と天球儀（知的・落ち着いた）

```text
【雰囲気C：アンティークの星図と天球儀】
- 色：深い藍 #14213D、墨 #0E1426、真鍮 #B08D57（細い線だけ）、古い紙の色 #E9DFC7（見出しの帯など少しだけ）。
- 背景：古い星図のような細い線の星座図と、天球儀の円弧と目盛り。線は細く、背景の明るさは低く。
```

### D：宝石とステンドグラス（華やか・神秘的）

```text
【雰囲気D：宝石とステンドグラス】
- 色：黒に近い夜 #07070C、瑠璃 #1F3FA8、紫水晶 #6A3FB5、ルビー #A0213B、エメラルド #1E7A55（どれも暗めに）、鉛の線 #1A1A1A。
- 背景：画面いっぱいのステンドグラスの模様そのものを、暗く落とした色で（建物や窓の形は描かず、ガラスの模様だけ）。ガラス越しの光はごく弱く。
- 部品：パネルの枠だけをステンドグラス風に（黒い鉛線で区切った宝石色の細い帯）。パネルの中は暗く無地。
- ひとことで：神秘的で華やか。ただし盤面のまわりは暗く静かにして、オーブがいちばん目立つ。
```

### D2：夜明けのステンドグラス（D を明るく軽やかに）

```text
【雰囲気D2：夜明けのステンドグラス】
- 色：夜明けの青 #2B4A8B → #6E8FD0、淡い金 #E9C46A、乳白のガラス #DCE3F0、差し色の淡いばら色 #C97A95（少しだけ）、鉛の線 #22283A。
- 背景：朝の光がごく弱く透ける、淡い青と乳白のステンドグラスの模様。ガラスの区切りは大きめで、数を少なく。建物や窓の形は描かない。
- 部品：パネルの枠は細い鉛線で区切った淡い青と金のガラス。パネルの中は半透明の濃い青。
- ひとことで：D の華やかさはそのまま、重くならない明るさ。盤面のまわりだけは濃い青で落ち着かせる。
```

### D3：星図のステンドグラス（D の模様を星座で組み立てる）

```text
【雰囲気D3：星図のステンドグラス】
- 色：D と同じ（黒に近い夜 #07070C、瑠璃 #1F3FA8、紫水晶 #6A3FB5、ルビー #A0213B、エメラルド #1E7A55、鉛の線 #1A1A1A）に、星の点だけ淡い金 #E9C46A。
- 背景：大きな円をいくつもの同心円と放射の線で区切った、天球の星図のようなステンドグラスの模様。区切りの中に星座の点と線が金で入る。建物や窓の形は描かない。
- 部品：パネルの四隅に、小さな円形のステンドグラスの飾り（星座の点と線入り）。枠の辺は細い鉛線だけ。
- ひとことで：神秘的で、このゲームならではの星座らしさがいちばん強い。
```

### E：古代ギリシャのモザイク（衣装の古代ギリシャ風と合う）

```text
【雰囲気E：古代ギリシャのモザイク】
- 色：深い青のラピスラズリ #1E2F6B、夜の紺 #10183A、テラコッタ #B5643C、大理石の白 #E9E4DA、くすんだ金 #C9A24E。
- 背景：小石やタイルを並べた古代のモザイク画で描いた夜空と星座。石の一つ一つが見えるくらいの粗さで、色の数は少なく。柱や神殿は描かない。
- 部品：パネルの枠は、白とテラコッタの小さなタイルで作った雷文（メアンダー、四角い渦が続く古代ギリシャの縁模様）。パネルの中は濃い紺の無地。
- ひとことで：手ざわりのある石の質感。古代ギリシャの空気が、建物なしで伝わる。
```

### F：古代ギリシャの壺絵（黒地に赤茶の線画）

```text
【雰囲気F：古代ギリシャの壺絵】
- 色：つやのない黒 #141012、素焼きの赤茶 #B9603A、くすんだ白 #E6DCCB（細い線だけ）、差し色の深い青 #23305E（ごく少し）。
- 背景：黒地に、赤茶の細い線で描いた星座と星（古代ギリシャの壺に描かれた絵のような線画）。曲線の帯と雷文の縁取り。柱や神殿は描かない。
- 部品：パネルとボタンの枠は、赤茶の雷文や波の文様の帯。主なボタンはくすんだ白の地に赤茶の縁（赤のオーブと見分けやすいように）。
- ひとことで：きりっとした2色の線画。ほかのゲームと見間違えにくい。
```

### G：切り絵の夜空（紙を重ねた影絵）

```text
【雰囲気G：切り絵の夜空】
- 色：紺の濃淡 #0D1433 → #1C2A5E → #34477F（紙の層ごとに1段ずつ明るく）、金の紙 #D9B45A（星と枠の線だけ）。
- 背景：紙を3層重ねた切り絵の夜空。雲と星座の形が紙の層になり、層の間にごく薄い影。建物は描かない。
- 部品：パネルは紙の層を1枚重ねたように、ふちにごく薄い影。枠は金の紙を細く切った線。
```

### H：星を映す夜の海

```text
【雰囲気H：星を映す夜の海】
- 色：夜空の紺 #0A1030、海の深い青 #0F2448、水平線のかすかな明かり #3B4F86、星と波の線は淡い金 #E9C46A と白 #E8E4D8。
```

### I：金糸の刺繍

```text
【雰囲気I：金糸の刺繍】
- 色：濃紺の布 #121A3D、深い紫の布 #2A1E4F（パネルの地）、金糸 #D8B25A、銀糸 #BFC6D6（少し）。
```

## 画面（1つ選ぶ）

### ホーム

```text
【画面：ホーム】
- いちばん上：左にプレイヤーの丸いアイコン枠（中は空）と名前の帯、右に通貨の小さな帯と、丸い小さなボタン2つ。
- その下：タイトルロゴ「ASTRA CHRONICLE」（細めのセリフ体の英字。金の細い線で、星や星座の線を少しだけあしらう）。
- 中央（画面の高さの約35%）：仲間3人が立つ場所。人物は描かず、3つの星座の線画（点と細い線）がうっすら光り、足元に名前の入る小さな帯（文字なし）だけを置く。
- 左端に縦に並ぶ菱形の小さなアイコンボタン4つ、右端にも4つ（中は単純な線のアイコン）。右のいちばん上（ガチャ）だけ、ほんの少し明るく。
- 下のほう：横幅いっぱいの大きな金色の主ボタン（冒険。文字なし）、その下に丸みのある四角いボタン3つ（アイコンだけ）。
- その下：細いスタミナのバーと、横長のイベントのバナー枠（中は抽象的な夜空の模様だけ）。
- いちばん下：5つのアイコンが並ぶタブバー。
```

### バトル

```text
【画面：バトル】
- いちばん上：細い帯（ステージ番号の小さな枠、小さな丸いボタン2つ）。
- その下（画面の高さの約18%）：敵が入る場所。魔獣は描かず、暗い背景と、名前の帯と、紫〜ピンクの横長のHPバーだけ。
- 中央：5×5のパズルの盤面を画面の横幅いっぱいに。25個のオーブ（4色がまんべんなく混ざる）。マス目の交点16か所に小さな金の点。2×2の4マスが細い金の枠で選ばれている。盤面の地は暗く、つや消し。
```

## 背景の部品（2026-11-03。仕様書 18.3 の「背景」）

アプリに組み込む背景画像を作るためのプロンプト。上の UI デザイン案とは違い、ボタン・枠・人物は描かず、空と雲だけを描く。**次の3つを1つにまとめたものを、画面ごとにそのまま貼る**（ユーザーへはまとめた形で渡す）。目標画像 `docs/ui-reference/10-target-home.jpg` を添付する。

- 出力は縦長（1024×1536）。画面の縦横比（約 9:19.5）より短いので、上下の端に空を足して伸ばす（上下の2割は空と雲が続くだけにしてもらう）。iPad では左右を少し切る。
- 仕上がった画像は 1320×2868px（iPhone）に整えて組み込む。

```text
【共通：背景だけを描く】
スマートフォン縦画面のファンタジーRPG「アストラクロニクル」の、画面の背景画像を1枚描いてください。この背景の上に、ボタン・パネル・キャラクターなどをアプリ側で重ねます。
添付の画像は目指す見た目の画面です。夜空の色・雲の質感・空気感だけを参考にし、画像の中のボタン・枠・ロゴ・アイコン・人物・星座の絵は描かないでください。
- 背景だけを描く。ボタン・枠・パネル・帯・アイコン・文字・ロゴ・数字は描かない。人物・動物・魔獣・星座の絵（人や動物の形の線画）も描かない。
- 城・神殿・塔・遺跡・家・柱・アーチ・宙に浮いた島などの建物、山・木・地面は描かない。空と雲だけで作る。
- 縦長の、正面から見た平らな1枚の絵。額縁・スマートフォンの枠・余白は入れない。
- 上の端と下の端の約2割は、空と雲が同じように続くだけにする（あとで上下に空を足して縦長の画面に合わせるため）。
- 見どころは中央に寄せ、左右の端を少し切っても成り立つようにする（iPad で使うため）。
- 色：夜空 #0D1638（上）→ #1E2A54（下）、雲 #273569 → #43518A。金 #D49B59〜#F1C073（いちばん明るい所 #FCE5A7）はごく少しだけ。
```

画像生成らしさを抑える指定（背景用）：

```text
【仕上げの指定（画像生成らしさを避ける）】
- 色：指定した色コードとその明暗だけを使う。全体に黄色や茶色のフィルターをかけない。
- 雲：紙を何枚か重ねて切り抜いたような、輪郭のなだらかな平たい雲の層（2〜3層）。綿のような写真風の雲、もや、煙にしない。
- 星：小さな点の星を控えめに散らす。十字に光る星は画面全体で5個以下。光の粒・キラキラ・流れ星・光の筋・レンズフレア・ぼけ玉は入れない。
- 光：全体にやわらかく暗め。強く光る所を作らない（上に重ねるボタンとオーブを目立たせるため）。
- 質感：つや消し。ほんのわずかな紙の粒子感はよい。3DCG・写真・油絵のような質感にしない。
- 飾り：金の細い線を使うなら、ゆるやかな円弧を1〜2本だけ。唐草や装飾の模様は入れない。
- 構図：左右対称の豪華な構図や、ポスターのような劇的な演出にしない。毎日見ても疲れない、静かな背景。
```

画面ごと（1つ選ぶ）：

```text
【画面：ホーム】
- 画面の中ほど（上から35〜65%）に仲間3人が立つので、その後ろだけ紺の夜空がほんのり明るくなる程度に（#2A3870 くらい）。光の柱や後光にはしない。
- 上のほうは、雲の切れ間から見える広い夜空。
- 下の4割はボタンやバナーが重なるので、雲の層を低く静かに。
```

## 直すときの追い指示

出てきた画像に対して、そのまま送れる短い指示。

| 気になる所 | 送る文 |
|---|---|
| 全体が黄色っぽい・セピアっぽい | `全体の黄ばみを取って、指定した色コードどおりの色に戻してください。白は白、紺は紺に。` |
| どこもかしこも光っている | `光っている所を半分以下に。光るのはオーブと選ばれている部品だけにしてください。` |
| キラキラが多すぎる | `キラキラした光と粒を画面全体で5個以下に減らしてください。` |
| つるつる・3DCGっぽい | `つや消しの2Dのゲーム画面の質感にしてください。光沢と立体感を弱く。` |
| 装飾がうるさい | `装飾を半分に減らし、星・星座の線・円弧だけにしてください。パネルの中は無地に。` |
| 文字のようなものが出た | `意味のない文字や記号を消して、その場所は無地の帯にしてください。` |
| 人物が描かれた | `人物と生き物を消して、その場所は背景だけにしてください。` |
| 建物が描かれた | `城・神殿・塔・柱・アーチ・浮いた島などの建物を消して、背景は空と模様だけにしてください。` |
| スマホの枠や斜めの見え方 | `端末の枠を消して、画面を正面からそのまま見たスクリーンショットにしてください。` |
| オーブが目立たない | `背景と枠の彩度を下げて、オーブの4色がいちばん鮮やかに見えるようにしてください。` |
| 部品が整列していない | `部品を縦横の線にそろえて整列させ、左右の余白を同じにしてください。` |
