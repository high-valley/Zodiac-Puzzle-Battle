# 雰囲気を決めるための画像生成プロンプト

仕様書 11章（画面構成）・18章（アート素材）をもとに、画面全体の雰囲気の案を何パターンか出すためのプロンプト。仕様書 18.1 の手順1にあたる。気に入った案が決まったら、部品ごとの書き出し用プロンプト（18.3）を別に作る。

## 使い方

1. 下の **共通の前提** を毎回いちばん上に貼る。
2. **雰囲気の方向（A〜D）** から1つ選んで続けて貼る。
3. **画面** から1つ選んで続けて貼る。
4. 縦長で出力する（実機は 9:19.5 くらいの縦長。生成ツールで選べる縦長の最大サイズ、たとえば 1024×1536 の 2:3 でよい。上下が実機より短くなる分、下の画面の指定は詰まって描かれる）。

おすすめの順番：まず「ホーム」を A〜D の4パターンで出して方向を絞る → 選んだ方向で「バトル」→ 残りの画面。同じ方向の画面どうしは、1枚目の画像を添付して「この画像と同じ絵柄・色・装飾で」と書き足すと揃いやすい。

### 気をつけること

- **文字はほぼ入れない**。生成した日本語は崩れやすいので、ボタンや見出しは無地の帯にしてもらう（画面の文字はアプリ側で描く。仕様書 18.2）。ロゴだけは入れてよい。
- ロゴは英字の「ASTRA CHRONICLE」で出してもらう（英字のほうが崩れにくい）。カタカナの「アストラクロニクル」はアプリ側で重ねるか、ロゴの部品を作るときに別に考える。
- ルールに関わる部分（盤面が5×5、オーブの記号、必殺の形）は画像だと崩れやすい。崩れていても雰囲気の比較には使えるので、気にせず雰囲気だけ見る。
- 実在の作家名・作品名・ゲーム名は入れない。
- 衣装の露出の度合いは未決定（仕様書 16章-17）。年齢区分の見立て（19.5）では、露出を控えめにすると低い区分も狙えるので、ひとまず「控えめ」で出す。違う度合いを見たいときはその行を書き換える。

## 共通の前提（毎回貼る）

```text
スマートフォン縦画面のファンタジーRPG「アストラクロニクル（ASTRA CHRONICLE）」のゲーム画面のイメージ画像を作ってください。

【ゲームの内容】
12星座をモチーフにしたキャラクターが、パズルで魔獣と戦うゲーム。パズルは5×5のマス目に丸い宝珠（オーブ）が並び、2×2の4個を回して、同じ色を縦か横に3個以上そろえて消す。

【必ず守ること】
- 画面は縦長のスマートフォン1画面分。上下の端（時計やホームバーの位置）には大事なものを置かない。
- ボタン・見出し・数値・説明の文字は入れず、文字が入る場所は無地の帯や枠にする。タイトルロゴだけは文字を入れてよい。
- 画面でいちばん鮮やかなのはオーブの4色（赤・青・緑・ピンク）。背景・枠・キャラクターは盤面のまわりで彩度と明るさを抑え、オーブがいちばん目立つようにする。
- オーブは4色とも同じ丸い宝珠で、中に色ごとに違う白い記号が入る：赤＝三角、青＝ひし形、緑＝四角、ピンク＝ハート。
- キャラクターはアニメ調。衣装の露出は控えめ（胸元や脚を大きく出さない）。
- 血や残酷な表現は入れない。
- 装飾は見出し・枠・主なボタンに集め、パズルの盤面のまわりは静かにする。

【キャラクター（最初の3人）】
- おひつじ座：赤い髪の青年。金色の巻いた角、赤と白の鎧とマント、剣。勇ましい表情。
- いて座：長い青い髪の女性。髪に金の星飾り、金の弓、青い衣装（露出は控えめ）。
- おとめ座：長い金髪の女性。白い花と星のサークレット、白とピンクの衣装、祈る手。
- 敵「星喰い」：紫の結晶でできた竜のような魔獣。
- 各キャラクターの背後に、そのキャラクターの星座の線画（星を光る線で結んだ図）がうっすら光る。
```

## 雰囲気の方向（1つ選ぶ）

### A：紺と金の星空神殿（今の方向・王道）

```text
【雰囲気】深い紺から紫の夜空。宙に浮かぶ白い石の神殿の遺跡と、流れ落ちる滝。満天の星と天の川。金の装飾枠と金文字、細い金線の唐草と星の飾り。荘厳で、きらびやかな王道のファンタジー。
```

### B：夜明けのパステル（やわらかい・親しみやすい）

```text
【雰囲気】夜明け前の空。薄紫・桃色・水色のグラデーション、雲の上に浮かぶ小さな神殿と星の花畑。枠は白とシャンパンゴールドの丸みのある形。光はふんわりとやさしく、全体に明るく親しみやすい。絵本のような柔らかさ。ただしオーブの4色はくっきり鮮やかに。
```

### C：アンティークの星図と天球儀（知的・落ち着いた）

```text
【雰囲気】深い藍色の地に、古い星図のような細い金の線と星座の線画。真鍮の天球儀・アストロラーベの歯車や目盛りを枠の飾りに使う。紙の質感はほんのり。落ち着いていて知的、大人っぽい。枠は細く直線的で、角に小さな星。
```

### D：宝石とステンドグラス（華やか・神秘的）

```text
【雰囲気】黒に近い夜の聖堂。枠はステンドグラスのように、黒い鉛線で区切られた宝石色（瑠璃・紫水晶・ルビー・エメラルド）のガラス。光がガラスを通して差し込み、床に色の光が落ちる。神秘的で華やか。盤面のまわりだけは暗く静かにして、オーブを目立たせる。
```

## 画面（1つ選ぶ）

### ホーム

```text
【画面：ホーム】
- いちばん上：左にプレイヤーの丸いアイコンと名前の帯、右に通貨2種類の小さな帯と、丸い小さなボタン2つ。
- その下：タイトルロゴ「ASTRA CHRONICLE」（金色の装飾的なセリフ体の英字、大きく。星や星座の線をあしらう）。
- 中央：おひつじ座・いて座・おとめ座の3人を大きく、ポーズを取って並べる。背後にそれぞれの星座の線画が光る。3人の足元に、名前の入る小さな帯（文字なし）。
- 左端に縦に並ぶ菱形の小さなアイコン4つ（お知らせ・プレゼント・ミッション・交換所）、右端にも4つ（ガチャ・ショップ・フレンド・ギルド）。ガチャだけ少し光らせる。
- 下のほう：横幅いっぱいの大きな金色の「冒険」ボタン（文字なし）、その下に丸みのある四角いボタン3つ（編成・育成・図鑑、アイコンだけ）。
- その下：細いスタミナのバーと、横長の期間限定イベントのバナー。
- いちばん下：5つのアイコンが並ぶタブバー（ホーム・クエスト・編成・育成・メニュー）。
```

### バトル

```text
【画面：バトル】
- いちばん上：細い帯（ステージ番号、小さな丸いボタン2つ）。
- その下：敵「星喰い」を大きく。名前の帯と、紫〜ピンクのHPバー。
- 中央：5×5のパズルの盤面を画面の横幅いっぱいに。オーブは赤・青・緑・ピンクの4色の丸い宝珠で、中に白い記号（三角・ひし形・四角・ハート）。マス目の交点16か所に小さな金の星。2×2の4マスが金の枠で選ばれている。盤面の地は暗く控えめ。
- 盤面のすぐ下：左に残り回数を示す金の点3つ、右に金色の「攻撃」ボタン（文字なし）。
- その下：左回転・右回転の矢印ボタンと、その間に必殺技の形の小さな図（3×3の点）。
- その下：3人のキャラクターのバストアップのカード3枚を横に並べる。左のおひつじ座のカードが金色に光って選ばれている。
- いちばん下：横長の緑のHPバー1本（パーティー共通）。
- 敵の欄に、ダメージの数値と「連鎖」の光の演出が重なっている瞬間にしてもよい（盤面には重ねない）。
```

### クエスト選択

```text
【画面：クエスト選択】
- いちばん上：戻るボタンと、章を切り替える左右の矢印に挟まれた章名の帯。
- 中央：章のマップ。夜空に浮かぶ島や神殿の上に、5つのステージの光る点が光の道でつながる。各点の下に小さな星3つ（取った★）。最後の点は鍵がかかっている。
- 下：選んだステージの詳細パネル（敵の小さな絵、名前の帯、紹介文の帯）と、大きな金色の「出撃」ボタン（文字なし）。
- いちばん下：タブバー。
```

### 編成

```text
【画面：編成】
- いちばん上：戻るボタンと画面名の帯。
- 上部：出撃する3人の大きな枠を横に3つ。それぞれにキャラクターの全身またはバストアップ、星座記号の丸いバッジ、名前とレベルの帯、必殺技の形の小さな図。
- その下：パーティーHPの緑のバー。
- 下部：12星座のキャラクターの小さなカードが3列で並ぶ一覧（星座記号のバッジと名前の帯）。出撃中の3人のカードに金の印。
- いちばん下：タブバー。
```

### 育成（キャラクター詳細）

```text
【画面：育成（いて座の詳細）】
- 上部：左にいて座の全身の立ち絵（背後に弓を引く半人半馬の星座の線画）、右に名前・英名・星座記号・役割の帯。
- 中央：レベルと経験値のバーのパネル。
- その下：色ごとの技のパネル（赤・青・緑・ピンクの小さな丸と、技名と数値の帯）。
- その下：必殺技のパネル。青い十字の形の図（中央と上下左右の5個）と、技名の帯。
- いちばん下：前後のキャラクターへの切り替えボタンと、タブバー。
```

### リザルト（勝利）

```text
【画面：リザルト（勝利）】
- 上部：「勝利」の大きな金の見出し（この2文字だけは入れてよい）。
- その下：おひつじ座・いて座・おとめ座の3人が喜ぶ姿。背後に星座の線画と光の粒。
- 中央：大きな金の星3つ（評価★3）。
- その下：記録のパネル（ターン数・最大連鎖・必殺の回数・与えたダメージの4つの小さな枠、文字なし）と、経験値のパネル（3人の小さなアイコンとバー）。
- いちばん下：大きな金色の「次へ」ボタンと、小さなボタン2つ（文字なし）。
```

## iPad 用（必要なら）

iPad でも遊べるようにしたので（仕様書 11.2）、iPad の見え方も見たいときは、画面のプロンプトの後に次を足す。

```text
【端末】iPad の縦画面（縦横比 3:4）。中央の列にゲーム画面を置き、左右の余白は背景の夜空と装飾で埋める。パズルの盤面はスマートフォンより大きく見せる。
```
