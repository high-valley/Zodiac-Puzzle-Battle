# キャラ絵を確かめるための画像生成プロンプト

`docs/character-design.md` で決まったキャラの見た目を、絵で確かめるためのプロンプト。ここで出す絵は**確認用**で、アプリにそのまま入れる部品（仕様書 18.3）は、見た目が固まってから別に作る。

## 使い方

1. **共通の前提** → **画像生成らしさを抑える指定** → **キャラ1人分** の順に貼る。
2. 縦長（たとえば 1024×1536）で出す。
3. 絵柄をそろえたいときは、目標画像 `docs/ui-reference/10-target-home.jpg` を添付して「絵柄（線と塗り）だけ参考に。キャラの見た目は下の指定に従う」と書き足す（目標画像の人物は旧案の見た目なので、髪や衣装はまねしない）。
4. 気になる所は下の **直すときの追い指示** をそのまま送る。
5. 1人ずつ決まったら、3人並びのプロンプトで並べたときの釣り合いを見る。

---

## 共通の前提（毎回貼る）

```text
スマートフォンのファンタジーRPG「アストラクロニクル」のキャラクターの立ち絵を1枚描いてください。キャラクターの見た目を確かめるための絵です。

【絵柄】
- 日本のアニメ・ゲーム調。くっきりした線画に、影は2〜3段のアニメ塗り（セル塗り）。
- 年ごろは10代後半〜20代前半に見えるように。等身はすらりと7頭身くらい。
- 古代ギリシャ風の衣装（布を体に巻いたり肩で留めたりする衣、ひだのある亜麻の布、肩の留め金、編み上げのサンダル）。中世の板金鎧、現代の服、ファスナーやボタンは描かない。
- 露出は控えめ（胸元や脚を大きく出さない）。血や残酷な表現はなし。

【構図】
- 全身。頭のてっぺんから足先まで画面に入れ、まわりに少し余白を残す。
- 体を少し斜めに向けた自然な立ち姿（真正面の直立ではなく）。顔はこちらに向ける。
- 背景は無地の明るい灰色（#E9E7E3）だけ。影は足元にうっすら。背景の模様・景色・光の演出は入れない（あとで切り抜くため）。
- 文字・ロゴ・サイン・枠は入れない。
```

## 画像生成らしさを抑える指定（毎回貼る）

```text
【仕上げの指定（画像生成らしさを避ける）】
- 色：下のキャラの指定にある色コードとその明暗だけを使う。全体に黄色や茶色のフィルターをかけない。
- 光：光源は左上の1つだけ。体や衣装のまわりに光のにじみ（グロー）、キラキラの粒、光の筋、レンズフレアを付けない。
- 質感：肌はなめらかなアニメ塗りで、つやつやの光沢や化粧品の広告のような質感にしない。布はつや消し。金属は金具の小さな反射だけ。
- 目：瞳のハイライトは1〜2個まで。星やハートの形の瞳、極端に大きい目にしない。
- 飾り：装身具は下のキャラの指定にあるものだけ。宝石・鎖・リボン・羽根を足さない。
- 線：線の太さはそろえ、輪郭はくっきり。ぼかさない。
- 手：指は5本ずつ、自然な形で。持ち物はしっかり握る。
- 雰囲気：ポスターのような派手な演出ではなく、キャラクターの設定画のように、見た目がはっきり分かる落ち着いた1枚。
```

## キャラ1人分（1つ選ぶ）

### おひつじ座

```text
【キャラクター：おひつじ座の星座の精】
- 男性、18歳くらいに見える青年。まっすぐな熱血リーダー。明るく勇ましい表情で、口元に自信のある笑み。
- 髪：赤い短髪（#C8322B）。少し跳ねた、動きやすい髪型。
- 目：琥珀色（#E0A030）。
- 体の特徴：頭の横に、金色の巻いた羊の角（#D4A84A）が左右1本ずつ。角はひと目で羊と分かる大きさで、耳の上あたりから後ろへ巻く。
- 衣装：膝丈の白いキトン（#F2EEE6）に、茶色の革の胸当て（#7A4E2E）。肩から赤いクラミュス（短い外套、#B3262B）をかけ、外套のふちに金色の羊毛のふわっとした飾り。腰に革の帯、編み上げの革のサンダル。
- 持ち物：右手に青銅の短い剣（#B07A3C、まっすぐな両刃）。
- ポーズ：剣を軽く構え、前に一歩踏み出しかけた姿勢。
```

### いて座

```text
【キャラクター：いて座の星座の精】
- 女性、18歳くらいに見える少女。自由で明るい旅人。楽しそうな笑顔で、遠くを見るような目つき。
- 髪：青い長い髪（#2F5FBF）を頭の高い位置で一つに結び、馬の尾のように背中へ流れる。前髪は軽め。髪に小さな金の星の飾り（#D9B45A）が1つ。
- 目：金色（#E2B23E）。
- 体の特徴：頭の上に小さな馬の耳（髪と同じ青、内側は淡い色）が左右1つずつ。人の耳はない。
- 衣装：膝丈の青いキトン（#3D6FD1）に細い帯。肩に生成りの旅の外套（#CDBB9A）を留め金で留める。足元は編み上げのサンダル。
- 持ち物：金の弓（#D9B45A、優美な曲線、装飾は控えめ）を左手に持ち、背中に矢筒。
- ポーズ：弓を持った手を下ろし、もう片方の手で外套の端を押さえ、風に吹かれて振り返りかけた姿勢。
```

### おとめ座

```text
【キャラクター：おとめ座の星座の精】
- 女性、18歳くらいに見える少女。ていねいで世話好き、少し心配性。やさしい穏やかな微笑み。
- 髪：淡い金色（クリーム色寄り、#EAD9A6）の長い髪を下ろし、毛先がゆるく波打つ。頭に麦の穂と小さな白い花で編んだ冠（麦 #D8B66A、花は白）。
- 目：薄い紫（#B9A3D9）。
- 体の特徴：背中に小さな白い翼（#FFFFFF、影は淡い灰色）が左右1枚ずつ。翼は肩幅くらいの小さめで、飛ぶためというより飾りのような大きさ。
- 衣装：白いキトン（#F4F1EC）に、淡いピンク（#E7A3C4）の布を肩から斜めにかける。腰に細いピンクの帯。足元は白い編み上げのサンダル。
- 持ち物：麦の穂の形を先に付けた細い杖（木の柄、穂は #D8B66A）を両手で胸の前に持つ。
- ポーズ：杖を胸の前で持ち、少し首をかしげて、祈るようにこちらを見る姿勢。
```

## 3人並び（1人ずつ決まってから、釣り合いを見る）

```text
上の3人（おひつじ座・いて座・おとめ座）を、同じ絵柄・同じ大きさで横に並べた1枚を描いてください。左から いて座・おひつじ座・おとめ座。3人とも全身で、背景は無地の明るい灰色（#E9E7E3）。キャラクター同士は重ならないように、少しずつ間をあける。身長は おひつじ座がいちばん高く、いて座とおとめ座は少し低い。
```

## 設定画（必要なら）

キャラ1人分のプロンプトの最後に足すと、正面・横・後ろの3方向を並べた設定画になる。スキン（着せ替え）を作るときや、部品を書き出すときの基準に使える。

```text
【追加：設定画】正面・横向き・後ろ向きの3方向の全身を、同じ大きさで横に並べてください。ポーズはまっすぐ立った自然な姿勢。色・髪型・角や耳や翼の形が3方向で同じになるように。
```

## 覚醒・進化した姿（覚醒を入れるときに使う）

基本の姿が決まったキャラについて、キャラ1人分のプロンプトの後ろに足す。基本の姿の見本（`docs/character-art/`）を添付し「添付のキャラが覚醒した姿」と書き添える。

```text
【追加：覚醒した姿】
- 添付のキャラクターが覚醒（進化）した姿を描いてください。同じ人物と分かるように、髪の色と髪型、目の色、体の特徴（角・耳・翼など）、星座の色は変えない。
- 年ごろは5歳くらい上に見えるように（20代前半〜後半）。顔立ちと体つきを少し大人びさせ、表情に落ち着きと自信を。
- 装いは古代ギリシャ風のまま、より豪華に：金糸の縁取りや刺繍のある上質な布、青銅や金の胸当て・すね当て・冠、星座の線や星をあしらった装飾、長い外套。体の特徴はひと回り立派に。
- 豪華さは素材と仕立てで出す。キラキラの光・光のにじみ・宝石の盛りすぎは使わない（上の仕上げの指定のまま）。
```

## 直すときの追い指示

| 気になる所 | 送る文 |
|---|---|
| 全体が黄色っぽい | `全体の黄ばみを取って、指定した色コードどおりの色に戻してください。` |
| 光っている・キラキラが多い | `体や衣装のまわりの光とキラキラを消して、落ち着いたアニメ塗りにしてください。` |
| 肌や衣装がつやつや | `光沢を弱めて、つや消しのアニメ塗りにしてください。` |
| 飾りが多い | `指定にない装身具（宝石・鎖・リボンなど）を消してください。` |
| 年が上（または下）に見える | `18歳くらいに見えるように、顔と体つきを少し若く（大人っぽく）してください。` |
| 衣装が中世や現代っぽい | `衣装を古代ギリシャ風（布を巻いて肩で留める衣、ひだのある布、サンダル）に直してください。` |
| 角・耳・翼の形が違う | `（角／耳／翼）の形を指定どおりに直してください：〔指定の文をそのまま〕` |
| 手や指がおかしい | `手を描き直して、指は5本ずつ、自然な形にしてください。` |
| 背景が描かれた | `背景を消して、無地の明るい灰色（#E9E7E3）にしてください。` |
| 文字が入った | `文字やサインを消してください。` |
