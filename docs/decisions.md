# 決定記録

仕様（`docs/game-spec.md`）を変えたときや、仕様に書かれていないことを決めたときに、新しいものを上に足す。

## 2026-11-01 M2（必殺演出・操作チュートリアル・効果音）で決めたこと

- **効果音は Web Audio で合成する**（音声ファイルを使わない）。オフラインで動き、素材の権利の心配がない。素材に差し替えるときは `src/audio/sound.ts` の鳴らし方だけ替える。出来事と音の対応は `src/audio/cues.ts`（純粋な関数）
- **効果音は最初からオン**。上の帯のボタンでオン/オフでき、端末に記憶する。iOS 17 以降は消音スイッチに従う種類（ambient）で鳴らす
- **遊び方は初回だけ自動で開く4枚の説明カード**（回す・3個そろえる・必殺・HP）。「?」ボタンでいつでも開ける。見たかどうかは端末に記憶する。仕様 11.2 の「段階的に開放する」チュートリアルは、キャラやオーブが増える段階で改めて作る
- **設定は localStorage に保存する**。保存できない環境では既定値で動く
- **必殺演出**：形のオーブを金の星座線で結んで光らせ、キャラ名と技名を盤面の上に出す。そのターンのダメージ・回復の数値と音を大きくする

## 2026-11-01 必殺に使ったオーブを消す（仕様 9.3・16 章 2 の変更）

- **理由**：仕様 9.3 のままだと、形が盤面に残り続けて毎ターン必殺が出る。特にピンク2×2は縦横3個に並ばないので消えず、おとめ座で離れた交点を回すだけで毎ターン＋110回復となり、負けなくなっていた
- **決めたこと**：必殺が出たら、その形のオーブを最初の消去で通常マッチと一緒に消す（重なったマスは1回だけ消す）
- 必殺だけで消えたオーブは通常効果（攻撃・回復）を出さない。縦横3個並びの通常マッチにもなっている分は、これまでどおり通常効果も出る
- 必殺だけの消去は連鎖の段数に数えない。そのあと落ちてきたオーブでできた通常マッチは1連鎖目から数える
- 仕様 9.3 の「必殺条件に使ったオーブは同じターンの通常消去判定と重複して構わない」はそのまま（重なっても両方の判定に使う）

## 2026-11-01 M1（最小プレイアブル）で決めたこと

- **画面は React を使わず、TypeScript ＋ DOM で書く**。M1 はバトル画面1枚だけなので。メニュー・編成・育成の画面が増える M3 以降で React の採用を改めて判断する
- **初期盤面は通常マッチが無いように作る**（仕様 7.3 の「要調整」）。色を1マスずつ決め、左に2個・上に2個同色が続く色を候補から外す。偶発的な初期マッチで1ターン目に勝手に消えるのを避けるため。必殺の形は初期盤面にあってもよい（仕様 9.3）
- **連鎖が8段に達したら、残ったマッチはそのまま次のターンに持ち越す**（次の回転のあとに消える）
- **補充の乱数の引き方**：左の列から、各列は下の空きから順に引く。再現性テストはこの順番に依存する
- **敵の行動は毎ターン一定量の攻撃**（`ENEMY.attack`）。敵HP・攻撃量・各キャラの係数・必殺の威力はすべて仮値で、`src/data/` で差し替える
- **おひつじ座の青「防御低下」はダメージだけ**。デバフの仕組みは後のフェーズで入れる
- **交点の判定**：押した位置にいちばん近い交点を選ぶ（盤面の端を押しても端の交点になる）。タップだけ（移動が閾値未満）は選択のみで、回転ボタンがその交点に効く
- **選んでいる交点は画面側で持つ**（仕様 13 章の `BattleState.selectedIntersection` はエンジンの状態に入れない）。選択はターンの結果に影響しないため
- **回復の出来事（`heal`）の量は、実際に増えた量**。最大HPで頭打ちになった分は含めず、満タンなら出来事自体を出さない
- **ターンの演出中は「やり直す」も押せない**（途中で新しい戦闘を作ると、古いターンの結果で上書きされるため）
- **package-lock.json はまだ無い**。作成した環境から npm レジストリに届かなかったため、CI は `npm install` で入れている。手元で `npm install` したら lock を足し、CI を `npm ci` に替える
