## 2026-11-03 みずがめ座を回復役に、おうし座を赤に（仕様書 1.15.0）

- **ユーザーの決定**：みずがめ座をヒーラーにする。赤が2人だけだったので、緑から1人（おうし座）を赤に移す
- これで必殺の色は赤（おひつじ・おうし・しし）・青（ふたご・さそり・いて）・緑（てんびん・やぎ・うお）・ピンク（かに・おとめ・みずがめ）の3人ずつ
- みずがめ座：ピンクで回復（係数9）、HP 110（ほかの回復役と同じ）、必殺は形はそのまま（一直線4個）でピンクの「宝瓶の慈雨」、回復量 110（作りやすい形なので、おとめ座と同じ）。技の名前は「命の水」
- おうし座：得意な色を赤（12）に、緑 10・青 9。必殺は形・威力はそのまま（T字・140）で赤の「金牛の猛進」。赤の技の名前を「突進」から「猛進」に
- 編成のルール（攻撃キャラ1人以上）は変えない。回復役が3人になったので、回復役だけの編成がありえるようになり、そのルールが働く
- 見本の絵の差し色（みずがめ座の青、おうし座の緑）は、仕上げの絵を作るときに考える

## 2026-11-03 押したオーブがスワイプした向きに動くように回す（仕様書 1.14.0）

- **ユーザーの要望**：4つを選んだあと、指でスライドさせた方向に回るようにしたい
- これまでは押した位置に関係なく「右・下へ＝時計回り」だったので、下の2個を押して右へすべらせると、押したオーブが左へ動いてしまった
- 押した位置（選んだ 2×2 の中心からのずれ）とすべらせた向きで決める：横なら上側か下側か、縦なら右側か左側かで向きが変わる。押したオーブが指について動く（輪を指で回す感覚）
- 交点のすぐ近く（0.15マス以内、`SWIPE.gripDeadCells`）を押したときは、どちら側か決められないので、これまでどおり右・下へ＝時計回り
- 回転ボタンの向きは変えない
- 「4個のどれかを押して」に合わせ、選んだままにする範囲を交点から0.8マスから、2×2 の4個の上ぜんぶ（1マス）に広げた。隣の交点に移りたいときは、その交点の星の近く（0.3マス以内）を押す（`SWIPE.neighborStarCells`）

## 2026-11-03 パズルの動きは「視差効果を減らす」でも同じに（仕様書 1.13.1）

- **ユーザーの決定**：「視差効果を減らす」がオンの人にも、標準でゆっくり回る動きを見せる。ユーザーが自分で決めた感覚のまま、だれでも同じようにパズルができるように統一したい
- 回す・消える・落ちる動き（盤面のオーブの動き）は、この設定に関係なく、ふつうと同じ時間で見せる。指に合わせて回す動きも同じ
- それ以外の演出（ダメージの数字、敵がゆれる、必殺の帯、遊び方の図の繰り返しなど）は、これまでどおり設定に合わせて減らす

## 2026-11-03 回す速さを決める・意図しない選び直しを防ぐ（仕様書 1.13.0）

- **ユーザーの決定**：画面で試した「ボタン 0.50秒／離したあと 0.50秒〜0.50秒／指に付く 90度」を既定の値にした（`DEFAULT_ROTATE_TUNING`）
- **ユーザーの要望**：意図していない交点を選んでしまうことがあるので、判定や範囲の印を工夫してほしい
  - 判定：今選んでいる交点の近く（縦横とも0.8マス以内）を押したときは、選んだままにする（`SWIPE.stickyCells`、`pickIntersection`）。これまでは0.5マス離れると隣の交点に移っていたので、選んでいる 2×2 の上でスワイプしようとして、少しずれて隣を選び、そのまま隣を回してしまうことがあった。隣の交点の真上を押せば、これまでどおり移れる
  - 印：枠を太く・地をうすい金に・四隅に星、まんなかの交点の星を大きくし、ほかの交点の星は控えめにした。押している間は枠を強く光らせ、別の交点に移ったときは一度光らせる（移ったことに気づけるように）。回す向きの矢印は紺の丸の上に大きく出す

## 2026-11-03 上下のスワイプでも回す・回す動きを遅く（仕様書 1.12.0）

- **ユーザーの要望**：回転が速すぎて回ったのか目で追えない。上下にスライドしても回るようにしてほしい
- **ユーザーの決定**：上下の向きは「下＝時計回り、上＝反時計回り」（右＝時計回りと合わせて「右・下で時計回り」と覚えられる）。押した位置で向きを変える案は採らなかった
- 斜め（横と縦が同じくらい）の動きは、これまでどおり回さない（どちらの向きか決められないため）
- 回転ボタンは 0.36秒 → 0.6秒。指を離したあとの残りは、これまで 0.07〜0.22秒で速く払うと一瞬で終わっていたので、回し始めで離したら 0.4〜0.56秒（ゆっくり離すほど長い）にし、残りが少ないほど短くする。また、指に合わせて回すのは 45 度までにした（大きく払うと指の動きだけで一瞬で回りきってしまい、目で追えなかったため。残りは指を離してから回す）。時間は `src/data/balance.ts` の `ROTATE_ANIM` と `releaseDuration` で変えられる
- 回す動きを遅くしたぶん、回している途中に「攻撃」を押したら、回しきってすぐ攻撃する（押しても効かないことがないように）

## 2026-11-03 仮の立ち絵の切り抜きをもう一度直す

- **ユーザーの指摘**：まだ白い部分が残っていた（おひつじ座の角の内側など）。小さなすき間が、背景の色との差が少し大きいために残っていた

- おうし座は白銀の髪が背景の色に近く、これまでの切り抜きで髪を背景と一緒に抜いていた（髪が暗く見えていたのはそのため。見本の絵の誤りではなかった）。おうし座だけ背景の見分けをずっと厳しくした
- 絵のファイル名の後ろに版（`?v=3`）を付け、端末に古い絵が残らないようにした。12人並びの見本（`docs/character-art/lineup.jpg`）も作り直した

## 2026-11-03 指に合わせて回す・補充の動き（仕様書 1.9.3）

- **ユーザーの声**：オーブの回転は、指の速度に合わせて回るくらいでよい。消えた所に上から補充されるなら、補充のアニメーションもっと分かりやすく
- **こちらで決めたこと**：
  - スワイプ中は横に動かした分だけ回り（1マス弱で90度）、指を離したら離したときの速さで回しきる。閾値に届かない・縦寄り・回せないときは元に戻す（回るかどうかの判定は今までと同じ。22pt と横寄りの判定）
  - 回転ボタンは前と同じ 0.36秒の円の動き
  - 補充：残ったオーブは元の位置からすべり落ち、新しいオーブは盤面の上から入ってくる。列ごとに少しずらし、着地で小さくはずむ。盤面の枠の外には見せない。時間は 0.23秒 → 約0.38秒

## 2026-11-03 アプリの版の表示と更新ボタン（仕様書 1.9.2）

- **ユーザーの依頼**：新しい版になっているか判断できないので、確認できる表示と更新ボタンがほしい
- **こちらで決めたこと**：
  - 版は「ビルドした日時＋コミットの先頭7文字」で表す（例：2026/11/3 12:40 版（e73ec03））。日時なら新しいか古いかがすぐ分かり、コミットの印で PR と突き合わせられる
  - 見る場所はメニュー（どの画面からも開ける）。公開されている最新の版も並べて出し、「最新の版に更新する」ボタンで読み直す
  - 公開されている最新の版は、ビルドのときに作る `version.json` をキャッシュせずに読む。読み直すときは URL に版の印（`?v=`）を付けて、古いページが使われないようにする
  - 起動したときに新しい版があれば、下のタブバーのすぐ上に小さな帯で知らせる（× で閉じられる）。上の帯のボタンをふさがないように下に置き、バトルとリザルトでは出さない（リザルトで読み直すと結果の表示が消えるため）。開発サーバーとテストでは版の印を入れず「開発版」と出す
  - iOS アプリでは App Store の更新に任せるので、M5 で扱いを決める

## 2026-11-02 1ターン3回まで回して「攻撃」で確定、形をL字・十字に戻す（仕様書 1.4.0）

- **ユーザーの提案と決定**：1ターンに最大3回まで回し、「攻撃」ボタンで確定する。回している間は何も消えず、必殺と消去は「攻撃」を押したときの盤面で判定する。やり直しの操作は付けない（戻したいときは逆に回して1回分を使う）。必殺の形はもとのL字・十字に戻す
- **なぜ十字が作れるようになるか**：これまで十字が作れなかったのは、3個並んだ時点で消えてしまうからだった。消えるのが「攻撃」のときだけになったので、途中で3個並べながら組み立てられる。1ターンで作れる割合（`npm run bench`、実戦に近い盤面 200 面、1回 → 2回以内 → 3回以内）は L字 3% → 28% → 56%、十字 0% → 11% → 31%、ピンク2×2 16% → 45% → 76%
- **こちらで決めたこと**：
  - 「攻撃」は1回以上回したときだけ押せる（0回で攻撃はできない）
  - 行動するキャラは「攻撃」を押すまで替えられる
  - 回している間、「攻撃」で消える3個並びに白い輪、選んでいるキャラの必殺の形に金の輪をつける（消えずに残っているので、何が起きるか見えるようにするため）
  - 回した途中の分と選んだキャラも保存する（再読み込みで回した分を取り消せないように、選んだキャラもそのまま戻るように）
  - 敵の数値を変えたので、このルールに変える前に保存された途中バトルは、はじめからになる（保存した状態が今のデータと合わないため）
  - 「攻撃」ボタンは盤面のすぐ下、残り回数の表示の横に置く（参考画像の「攻撃開始」ボタンにあたる）
- **数値の調整**：1ターンのダメージが約80から約160に増えたので、敵のHPと攻撃を作り直した。1ターンが長くなった（3回まで回して攻撃）ので、1戦のターン数の目安は 1-1 約5ターン 〜 1-5 約14ターンに下げた（1戦2〜4分の目安に合わせる）。★2の目標ターンも合わせて下げた
  - 上手な自動プレイヤー（skilled）：1-1 勝率100%・約5ターン、1-4 約92%・約12ターン、1-5 約76%・約14ターン。でたらめに回すと 1-1 は約1割、1-2 以降はまず勝てない
  - ★2の目標ターンは上手な人の平均くらいにしたので、★2に届くのは半分ほど（やり込みの目標）
  - 自動プレイヤーは3回までの回し方に合わせて作り直した。skilled は1回ずつ良い回し方を選び、必殺の形があと1〜2個ならそこへ近づける（上手な人の目安）。expert は3回までを全部調べる（上限の目安）
- 角・×字の記録（下の節）は経緯として残す

## 2026-11-01 M2（必殺演出・操作チュートリアル・効果音）で決めたこと

- **効果音は Web Audio で合成する**（音声ファイルを使わない）。オフラインで動き、素材の権利の心配がない。素材に差し替えるときは `src/audio/sound.ts` の鳴らし方だけ替える。出来事と音の対応は `src/audio/cues.ts`（純粋な関数）
- **効果音は最初からオン**。上の帯のボタンでオン/オフでき、端末に記憶する。iOS 17 以降は消音スイッチに従う種類（ambient）で鳴らす
- **遊び方は初回だけ自動で開く4枚の説明カード**（回す・3個そろえる・必殺・HP）。「?」ボタンでいつでも開ける。見たかどうかは端末に記憶する。仕様 11.2 の「段階的に開放する」チュートリアルは、キャラやオーブが増える段階で改めて作る
- **設定は localStorage に保存する**。保存できない環境では既定値で動く
- 遊び方は「とばす」や Escape で閉じても「見た」扱いにする（次からは自動で開かない）
- ターンの演出中は「?」（遊び方）も押せない。効果音のオン/オフは演出中も切り替えられる
- 音が出せない環境（AudioContext を作れない等）では、音なしでそのまま遊べる
- **必殺演出**：形のオーブを金の星座線で結んで光らせ、キャラ名と技名を盤面の上に出す。そのターンのダメージ・回復の数値と音を大きくする

## 2026-11-01 必殺に使ったオーブを消す（仕様 9.3・16 章 2 の変更）

- **理由**：仕様 9.3 のままだと、形が盤面に残り続けて毎ターン必殺が出る。特にピンク2×2は縦横3個に並ばないので消えず、おとめ座で離れた交点を回すだけで毎ターン＋110回復となり、負けなくなっていた
- **決めたこと**：必殺が出たら、その形のオーブを最初の消去で通常マッチと一緒に消す（重なったマスは1回だけ消す）
- 必殺だけで消えたオーブは通常効果（攻撃・回復）を出さない。縦横3個並びの通常マッチにもなっている分は、これまでどおり通常効果も出る
- 必殺だけの消去は連鎖の段数に数えない。そのあと落ちてきたオーブでできた通常マッチは1連鎖目から数える
- 仕様 9.3 の「必殺条件に使ったオーブは同じターンの通常消去判定と重複して構わない」はそのまま（重なっても両方の判定に使う）

## 2026-11-01 M1（最小プレイアブル）で決めたこと

- **画面は React を使わず、TypeScript ＋ DOM で書く**。M1 はバトル画面1枚だけなので。メニュー・編成・育成の画面が増える M3 以降で React の採用を改めて判断する
- **初期盤面は通常マッチが無いように作る**（仕様 7.3 の「要調整」）。色を1マスずつ決め、左に2個・上に2個同色が続く色を候補から外す。偶発的な初期マッチで1ターン目に勝手に消えるのを避けるため。必殺の形は初期盤面にあってもよい（仕様 9.3）
